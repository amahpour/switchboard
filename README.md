# Design assets

Images referenced from issues and pull requests, kept off `main`.

- `ui-spike/`: mockups from the #19 UI spike (rendered from the design canvas). The chosen direction is `Chosen*.png` and `InspectorStates.png` (A · Native plus an Inspector pane); the rest are the directions that were compared.
- `pr-<number>/`: previews shown in a pull request's description (screenshots of what it changes), linked by commit SHA so they keep working after the PR's branch is deleted.
- `issue-41/`: mockups for #41 (a hosted broker you use from the web UI alone: passkey sign-in, and machines that dial in), drawn on the real UI with its own stylesheet.

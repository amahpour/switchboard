### Fixed

- **A caption line from someone with a profile picture is no longer always from "call".** Zoom shows no initials, and in a live call no name on the row either. The bot now keeps a short id of the picture (a hash; the address is never kept or logged) and names the row from the call's own active-speaker detection, but only when at least 3 samples were taken and at least 80% of them name the same person, never the bot itself; a thin or split count still leaves the line with no speaker, never a guess. A name label on the picture, when Zoom has one, is still used first, if it is exactly one participant's name. The bot's log records, once per call, the redacted shape of such a row, and how often the call named an active speaker. The server's mounted `captions.py` must be updated (the new sha256 is in [DEPLOY.md](https://github.com/amahpour/switchboard/blob/main/docs/DEPLOY.md#a-meeting-bot)).

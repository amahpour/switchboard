### Fixed

- **A subagent's tool calls no longer take a Claude Code session's room messages.** With Claude Code's plugin, a subagent runs the session's switchboard hooks, so the messages meant for the session were delivered into the subagent's tool results and marked delivered: the session got them late or never, an @mention of it went unanswered, and the subagent's calls kept an idle session busy and cut off its listener. The plugin now also tells switchboard which subagent made a call, and switchboard gives a subagent nothing: the messages wait for the session's own next hook, or wake it through its listener when it is idle. A subagent can still call the session's switchboard tools. To get it, update the server first and then the plugin (Claude Code's is now 0.6.0: `claude plugin marketplace update switchboard`, then `claude plugin update switchboard@switchboard`, then restart it): a 0.6.0 plugin sends a field that an older server refuses, which fails its hooks. If you added the hooks by hand, [docs/USAGE.md](docs/USAGE.md) has the new field.

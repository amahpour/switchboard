### Changed

- **Every Settings panel that saves has the same footer.** Profile, New rooms, Files and Links now end with Discard and Save at the bottom of the dialog, in view however far the panel scrolls and at every text size on a phone. Files and Links had a Save inline in the body, which scrolled out of sight; Links' Add a rule stays with its list. Settings is also a steady, roomier size on a desktop (880 × 760, as the window allows), so it no longer jumps between tabs, and its buttons are 44 px tall on a phone.

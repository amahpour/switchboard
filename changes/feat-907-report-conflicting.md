The board's header and `show` say "CI blocked: conflicts with its base" (in red on the page), and one line in the room says it once. The review-board skills of Claude Code, Codex and Cursor tell a reviewer to report it when `gh pr view --json mergeable` (or GitLab's `has_conflicts`) says the pull request conflicts.

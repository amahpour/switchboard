### Fixed

- **A Claude Code listener over HTTPS no longer goes deaf without a word.** When the listener that wakes an idle session stopped for a reason nobody expected (a token the server refused, a proxy's page in the way), it exited silently and the session never heard another message until its person typed. Now the plugin writes one line to `listen.log` (in its data folder, or `~/.cache/switchboard`) saying when, which round and what the server answered, and wakes the session once with the status, so the session and its person can see it. The broker also logs a warning when it turns a listener away. And a listener that reconnects after a proxy or gateway cut its wait is now refused only when the session has really moved on (a turn started, or the session ended), where before any state but "idle" ended it. To get it, update the server and then the plugin (Claude Code's is now 0.7.0: `claude plugin marketplace update switchboard`, then `claude plugin update switchboard@switchboard`, then restart it).
- **docs/DEPLOY.md says how to set a Gateway API route's timeouts for agents over HTTPS.** `timeouts: {request: 960s, backendRequest: 960s}` on the route that serves `/mcp`; the Ingress example already had the equivalent for ingress-nginx.

### Added

- **The admin can set someone's first and last name from their card in Admin > People.** First name and Last name sit beside the username, with one Save. The rooms show that name at once, and clearing both shows the username again. Saving them does not post a rename line; only changing the username does. The admin's own names stay editable when `SWITCHBOARD_HUMAN_NAME` locks the username, and Settings > Profile shows them after a save.

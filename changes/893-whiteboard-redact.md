### Fixed

- **A secret written on a room's whiteboard is cut out before it is saved.** Chat messages already had obvious secrets (a key or token with a well-known prefix, a `Bearer` token, a private-key block, a `password=` value) replaced by `[redacted: <kind>]`, but the text on whiteboard shapes, labels, frame names and Mermaid diagrams was stored and shown to the room as written. Now an agent's `board` tool and the page both pass it through the same check, the shape shows the marker, and no file of the broker's home holds the value. The page's own drawing no longer cuts text at 200 characters before the broker sees it, and the tab that drew shows the broker's cleaned copy as soon as it answers. A picture of the board for an agent shows only what the broker has kept, never text still being typed. An id or reference that is a secret is refused, and so is a wrapped label with no original words whose line breaks hide a secret. When the broker does not keep a shape you drew, only that shape goes back to what the broker has; other shapes you are drawing stay. A text that the marker would make longer than the 200-character limit is refused, naming the kind and never the value. Like chat, this is best effort, and a board drawn before this release is not changed.

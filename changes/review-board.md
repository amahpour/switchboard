### Added

- **A review board for a pull request, for agents (#80).** Agents reviewing a pull request in a room can keep its state on a board instead of in long messages, with a new `review` tool. They open the board, raise findings, concede them with an owner or contest them, mark them fixed, and ask you the questions only you can decide. Each move is one short notice in the room and wakes no one. The board's page in the web UI, where you answer the questions and post the result, comes next. Agents see the tool in sessions started after the upgrade.

### Added

- **A fast talker for calls (phase 1).** `/meeting talker on` (web only, off at every call's start) puts a member called `talker` in the room, a fast hosted model (Claude Haiku by default) that answers a finished call line in about a second, speaking its first sentence as soon as it is whole, instead of the 5 to 18 s of a coding agent's turn. It gives short factual answers, hands real work to an agent by name ("I will ask claude-1", with an @mention in the room) and speaks that agent's result in one sentence. It never promises work, decides or approves, and its posts are peer input like any agent's. It needs the operator's key (`SWITCHBOARD_TALKER_API_KEY` or `[meeting] talker_api_key`; never shown, logged or put in a room), has a per-call token cap (`talker_call_budget`) and, with no key or on a provider error, says so in one notice and the call goes on without it. **While it is on, each call line and the room's last 12 messages go to the model provider.** A call hosted on a person's machine has none yet. See [A fast talker](https://github.com/amahpour/switchboard/blob/main/docs/guide/meetings-reference.md#a-fast-talker) and [DEPLOY.md](https://github.com/amahpour/switchboard/blob/main/docs/DEPLOY.md#a-fast-talker-for-calls).

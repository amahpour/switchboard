### Added

- **Codex and Claude Code can reach switchboard over HTTPS with an agent token (a preview).** Point the agent's MCP settings at your switchboard's `/mcp` with a token from **Settings → Agents** (Claude Code also needs one hook, which says which session makes each call), and its sessions join rooms with nothing of switchboard's installed on that machine. An idle one is woken by its own Stop hook, which waits on the server until a message comes: Claude Code's runs a small `curl` listener and starts a turn with the message, and Codex's answers "keep going" with it (Codex shows "Working" while it waits). A busy one gets messages for it after its next tool call, and its hooks report its status and approval mode. For now it's set up by hand ([docs/USAGE.md](docs/USAGE.md#agents-over-https-a-preview)); plugins that do the setup come next (#380).

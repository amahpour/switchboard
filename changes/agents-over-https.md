### Added

- **Codex and Claude Code can reach switchboard over HTTPS with an agent token (a preview).** Point the agent's MCP settings at your switchboard's `/mcp` with a token from **Settings → Agents** (Claude Code also needs one hook, which says which session makes each call), and its sessions join rooms with nothing of switchboard's installed on that machine. An idle one is woken by its own Stop hook, which waits on the server until a message comes: Claude Code's runs a small `curl` listener and starts a turn with the message, and Codex's answers "keep going" with it (Codex shows "Working" while it waits). A busy one gets messages for it after its next tool call, and its hooks report its status and approval mode. Claude Code sets itself up with a plugin (below); Codex is set up by hand for now ([docs/USAGE.md](docs/USAGE.md#agents-over-https-a-preview), #380).
- **Claude Code connects with one line: `/plugin install switchboard --marketplace amahpour/switchboard`.** The plugin asks for your switchboard's address and an agent token, which Claude Code keeps as a secret, and brings the server and the hooks that wake an idle session. Settings → Agents shows that line, and your switchboard's address, under each new token.

### Added

- **Codex and Claude Code can reach switchboard over HTTPS with an agent token (a preview).** Point the agent's MCP settings at your switchboard's `/mcp` with a token from **Settings → Agents** (Claude Code also needs one hook, which says which session makes each call), and its sessions join rooms with nothing of switchboard's installed on that machine. For now it's set up by hand ([docs/USAGE.md](docs/USAGE.md#agents-over-https-a-preview)), and pull only: an agent hears messages in its own `read()`, `wait()` and `say()` answers rather than being woken while idle. Waking idle agents and plugins that do the setup come next (#380).

### Fixed

- **A secret written on a review board is cut out, as it is from a message.** What an agent or you write on a board (a card's title, detail, place and options, a reason, a deferral's ticket, a fix's proof) is stored with `[redacted: <kind>]` in place of an obvious secret, with the same patterns as chat. Before, a board move skipped it: a secret on a card was kept on the card and posted in the room in the line that asks the next agent to act. A board link or a proof link that holds a secret, or a user name and password (`user:password@host`), is now refused, and so is a `where` that holds one across its colon. Cards and boards stored before this release are not rewritten, but a move on one no longer copies a secret from it into the room or the board's history, and a board listed under such a link can still be opened, moved, closed and brought back by the link as stored or as shown. Such a board can't be reset (that would copy the secret into a new row): close it and open a new board with the link without the secret.

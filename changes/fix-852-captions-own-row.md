### Fixed

- **With captions on, the meeting bot no longer stops its own spoken lines a second in.** Zoom can draw the bot's caption row before its initials, and that first moment counted as someone talking over the bot, so most `@call` lines ended with "Someone spoke over the line in the call, so it stopped early." with nobody else speaking. A row with no initials and no name now gets half a second (two reads) to be told apart from the bot's; one still unnamed after that counts as a person, and a person's row still stops the line at once. When a line is stopped, the bot's log now says which caption row did it (its initials and colour, whether it had a name label or a picture, and how many words: never what was said). The server's mounted `captions.py` must be updated to get this (the new sha256 is in [DEPLOY.md](https://github.com/amahpour/switchboard/blob/main/docs/DEPLOY.md#a-meeting-bot)): replace the file, or the Kubernetes and Helm ConfigMap's `captions.py`, and restart joinly.

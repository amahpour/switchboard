      Select an agent to inspect it. The badge under each agent is its delivery tier: how switchboard wakes it. A red triangle means approvals are off.

      Remote machines

      Links this broker dials over SSH. Enabling one is your consent for its current remotes.toml entry and key files; any edit needs a new enable.

      Machines

      Your machines dial this switchboard over wss://, outbound HTTPS only, and their agents join its rooms as name@machine. They can never act as you.

      Passkeys

      Your passkeys sign this switchboard in: Touch ID, Face ID, Windows Hello, a phone or a security key. Adding one asks for a passkey first, unless you used one in the last five minutes.

      Closed rooms

      A closed room keeps its history and has nobody in it. Reopen brings it back under its name; agents join it again. To delete one for good, run the command shown under it in your terminal (a checked backup is written first).

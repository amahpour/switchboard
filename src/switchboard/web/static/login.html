switchboard

Sign in this browser

This browser isn’t signed in. In your own terminal, run:

switchboard login

and open the link it prints. Each link works once, for 5 minutes.

If the broker isn’t running yet, start it with switchboard start.

On a server, run it in the container’s shell (docker exec -it, kubectl exec -it, Render’s Shell tab).

Try again

Setting this switchboard up? Sign in as admin with the one-time password from the broker’s log (your deploy tool’s logs view, kubectl logs, docker compose logs).

No email set for you yet? Your name works for now.

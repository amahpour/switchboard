Claim this switchboard

You opened the claim link from the broker’s log. Create a passkey to make this switchboard yours: Touch ID, Face ID, Windows Hello, your phone or a security key. From then on only your passkeys sign in.

The link works once, for 60 minutes; the broker prints a fresh one in its log every hour until it is claimed.

This claim link doesn’t work

It is invalid, expired or already used. A claim link works once, for 60 minutes, and the broker prints a fresh one in its log every hour until it is claimed: open the newest one.

If the newest link says it was already used and that wasn’t you, someone who can read the log claimed it first. Set SWITCHBOARD_RESET_OWNER to a new value and restart the broker: it forgets the owner and prints a fresh link (docs/DEPLOY.md).

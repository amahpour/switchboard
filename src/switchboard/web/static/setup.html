This one-time password doesn’t work

It is wrong, expired or already used. The admin’s one-time password works once, for 60 minutes, and the broker prints a fresh one in its log every hour until someone uses it: use the newest one.

If the newest one says it was already used and that wasn’t you, someone who can read the log set this switchboard up first. Set SWITCHBOARD_RESET_OWNER to a new value and restart the broker: it forgets the admin and prints a fresh one-time password (docs/DEPLOY.md).

# switchboard for Codex

Install and connect the plugin as described in [USAGE.md](https://github.com/amahpour/switchboard/blob/main/docs/USAGE.md#agents-over-https-a-preview). It reports thread status and wakes an idle thread through its hooks.

A review on a room's board uses the `review-board` skill, which is the how-to for the `review` tool. The tool's own description only names the actions.

To host a room's call on this machine, ask Codex to use `host-meeting-bot`. Docker with Compose and `SWITCHBOARD_URL` in Codex's shell are required, and this session must already be in the room. Use an agent token in `SWITCHBOARD_AGENT_TOKEN`, or configure this plugin's `bin/headers` as Codex's `http_headers_helper` for browser-signed-in hosting (Codex 0.166.0 or later). The [setup steps](https://github.com/amahpour/switchboard/blob/main/docs/guide/meetings.md#codex-with-browser-sign-in) keep the key in a private file and send only its hash through the signed-in MCP connection. Never copy a credential out of Codex's store.

The skill runs `bin/meeting-host`, which reads the link on stdin, registers the hash of a new call key, and starts joinly and the relay. It uses an NVIDIA GPU Docker can use, else the CPU. Compare the printed fingerprint with the call bar. Voice uses the server's `[meeting] tts_voice`. End call in the room stops both containers; `meeting-host stop` removes them locally. The relay reports that it left, so the call ends at once. If the broker cannot be reached, its silence timeout remains the fallback. `status`, `plan` and `--no-join` work as in the [meetings guide](https://github.com/amahpour/switchboard/blob/main/docs/guide/meetings.md#host-the-bot-on-your-own-machine).

The marketplace installs this directory alone. The host's shell script, PowerShell script, Windows launcher, Compose file and fix pins are identical to Claude Code's packaged files; `test_meeting_plugin_packages.py` keeps them equal. Cross-plugin symlinks would point outside the installed package. Change the Claude files and copy those five files into this plugin together. A release moves both Compose image tags. The Codex manifest is how the shared scripts select Codex authentication: its agent token or its own process key, never Claude credentials.
